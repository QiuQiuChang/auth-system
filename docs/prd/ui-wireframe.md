## 5. 组件规范

### 5.1 卡片
- 宽度: 400px (响应式: min(400px, 90vw))
- 圆角: 16px
- 阴影: 0 8px 32px rgba(0, 0, 0, 0.2)
- 内边距: 40px
- 背景: #ffffff

### 5.2 输入框
- 高度: 44px
- 圆角: 8px
- 字号: 14px
- 占位符颜色: #bfbfbf

### 5.3 按钮
- 高度: 44px
- 圆角: 8px
- 字号: 16px
- 字重: 500
- 主按钮背景: #4361ee
- 主按钮悬停: #3651d4

### 5.4 过渡动画
- 页面切换: fade 淡入淡出, 300ms
- 卡片加载: 从下方滑入, 400ms
