# 登录注册系统 - 产品需求规格说明书

## 1. 项目概述

### 1.1 项目名称
Auth System - 前后端分离登录注册系统

### 1.2 项目背景
构建一个安全、高效的用户认证系统，支持用户注册、登录、Token 鉴权等核心功能。

### 1.3 技术栈
- **前端**: React 18 + Vite + TypeScript + Ant Design 5
- **后端**: Spring Boot 3.2.x + Java 17 + Spring Security + JWT
- **数据库**: MySQL 8.0

---

## 2. 功能需求

### 2.1 用户注册
- 用户名: 3-20 字符，仅支持字母、数字、下划线
- 邮箱: 合法邮箱格式，全局唯一
- 密码: 8 位以上，必须包含大写字母、小写字母和数字
- 前端实时校验 + 后端二次校验

### 2.2 用户登录
- 使用用户名 + 密码登录
- 登录成功返回 JWT Token (有效期 24 小时)
- 登录失败返回明确错误信息

### 2.3 Token 鉴权
- JWT Token 放入 Authorization 请求头
- 后端过滤器校验 Token 有效性
- Token 过期返回 401 状态码

### 2.4 获取用户信息
- 登录后可获取当前用户信息
- 返回用户 ID、用户名、邮箱、创建时间

---

## 3. 非功能需求

### 3.1 安全性
- 密码使用 BCrypt 加密存储
- JWT Token 使用 HS256 签名
- CORS 配置限制跨域访问

### 3.2 性能
- 接口响应时间 < 500ms
- 支持并发用户数 > 100

### 3.3 可用性
- 友好的错误提示信息
- 表单实时校验反馈
- 响应式设计，支持移动端

---

## 4. 用户角色

| 角色 | 权限 |
|------|------|
| 未登录用户 | 注册、登录 |
| 已登录用户 | 获取个人信息、退出登录 |

---

## 5. 状态机

```
[未登录] --注册--> [未登录]
[未登录] --登录成功--> [已登录]
[已登录] --Token过期--> [未登录]
[已登录] --退出登录--> [未登录]
```

---

## 6. 边界条件

### 6.1 注册场景
- 用户名已存在 -> 409 Conflict
- 邮箱已注册 -> 409 Conflict
- 密码强度不足 -> 400 Bad Request

### 6.2 登录场景
- 用户名不存在 -> 401 Unauthorized
- 密码错误 -> 401 Unauthorized

### 6.3 鉴权场景
- Token 缺失 -> 401 Unauthorized
- Token 无效 -> 401 Unauthorized
- Token 过期 -> 401 Unauthorized
