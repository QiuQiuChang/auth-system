## 🎯 多模态能力详解

### 1. 图片上传
- 支持格式：JPG, PNG, GIF, WebP
- 处理方式：转Base64编码
- 显示：缩略图预览 + 删除按钮
- 限制：前端可上传多张图片

### 2. 图片识别
- API端点：POST /api/chat/vision
- 消息格式：OpenAI Vision API兼容
- 积分消耗：20积分/次（含图片的对话）
- 模型：agnes-2.0-flash（支持vision）

### 3. 消息结构
```json
{
  "role": "user",
  "content": [
    {"type": "text", "text": "这张图片是什么？"},
    {"type": "image_url", "image_url": {"url": "data:image/jpeg;base64,..."}}
  ]
}
```

## 🔧 技术实现

### 后端架构
```
FileUploadController
  ↓ 
Base64编码
  ↓
MultimodalChatService
  ↓
Agnes AI Vision API
  ↓
识别结果
```

### 前端流程
```
用户上传图片
  ↓
显示预览
  ↓
输入文字
  ↓
发送组合消息
  ↓
显示AI回复
```

### API端点
- POST /api/upload/image - 图片上传
- POST /api/chat/vision - 多模态对话
- POST /api/chat/message - 纯文本对话（保留）

## 💰 积分策略

| 对话类型 | 积分消耗 | 说明 |
|---------|---------|------|
| 纯文本 | 10积分 | 使用 /chat/message |
| 含图片 | 20积分 | 使用 /chat/vision |
